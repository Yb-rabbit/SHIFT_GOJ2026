# SHIFT_GO2026

基于 **Unity 2022.3（URP）** 的网格解谜原型，主题围绕"移位 / 位移"展开。
目前处于**机制原型阶段**：核心玩法是一个可以反复试错的位流路由关卡，并支持在游戏内直接改关卡。

## 环境

| 项 | 说明 |
|---|---|
| Unity Editor | `2022.3.36f1` |
| 渲染管线 | URP 14.0.11 |
| 输入 | 旧版 InputManager（未启用 Input System Package） |
| UI | uGUI + 内置字体（不依赖 TextMeshPro） |
| 目标平台 | Windows Standalone |

## 快速开始

1. 用 Unity Hub 以 `2022.3.36f1` 打开本工程根目录。
2. 打开 `Assets/Scenes/Test_2_BitFlow.unity`。
3. 按 Play，然后用底部的 **PLAY / PAUSE / STEP / REPLAY** 观察位流推进。

## 玩法

- 位（0 / 1）由发射器按序列依次吐出，每个 tick 沿自身朝向前进一格。
- 路上的元件会改变位的走向或取值：**分流器**按值分两臂、**非门**取反、**过滤器**只放行指定值。
- 位撞墙、出界、或从元件的出口面逆行撞入 → 销毁。
- 所有接收器都**恰好收满且内容正确**才算通关；接收器配置可以在鼠标悬停时查看。

## 关卡编辑模式（BUILD MODE）

游戏内按 **B** 即可进入编辑模式，改动立刻反映到画面上，可以直接 PLAY 验证。完整按键、默认值、存档位置与常见问题见 **[docs/BUILD_MODE.md](docs/BUILD_MODE.md)**。

| 操作 | 作用 |
|---|---|
| 滚轮 | 切换当前元件（墙 → 发射器 → 接收器 → 分流器 → 非门 → 过滤器 → 擦除） |
| 左键 | 在格子上放置（该格已有元件则替换）；**按住拖动可以连续铺一片** |
| 右键 | 删除该格元件；**按住拖动可以连续擦一片**（`X` / `Delete` 也可删当前格） |
| 中键 / `R` | 把该格元件顺时针旋转 90° |
| `1` ~ `7` | 直接点选元件（键盘快捷方式，不记也行） |
| `F5` | 保存自定义关卡 |
| `F9` | 读取已保存的自定义关卡 |
| `B` | 进出编辑模式（`ESC` 也可退出） |

说明：

- 鼠标为主：底部按钮可直接点，场景里有 ghost 光标预览，**光标颜色 = 将要放下的元件颜色**，擦除时变红。
- 编辑只作用于**内存中的关卡草稿**，Asset 里的关卡资产不会被修改，退出 Play 后自然还原。
- 想保留改造成果用 `F5`，会写到 `Application.persistentDataPath/ShiftGoLevels/custom_level.json`。
- 编辑结果对 `REPLAY` 同样生效，可以边改边看能不能跑通。

## 画面怎么看

不靠文字也能读关卡，靠的是统一的视觉语言（悬停任意元件还会显示同样的说明）：

| 元件 | 外观 |
|---|---|
| 墙 | 高立方 |
| 发射器 | 矮宽块 + 朝外箭头 + 一排**序列点阵**（某位发出后会变暗） |
| 接收器 | 中块 + 进料面箭头 + 顶部进度条 + **目标序列点阵** |
| 分流器 | 小块 + 两条臂：**青色臂收 1、橙色臂收 0** |
| 非门 | **菱形**本体 + 输出箭头 |
| 过滤器 | **薄板**本体 + 出口箭头（颜色就是它放行的值） |

颜色语义全关统一：**青 = 1，橙 = 0**（位本身、分流器臂、序列点阵、过滤器出口都用这一套）。
所有方向指示都是"细杆 + 加宽的箭头头"，不会把进出方向看反。

## 目录

```
Assets/
├── Arts/       美术资源
├── Audio/      音频
├── Data/       关卡与元件数据（可在 Inspector 里查看）
├── Editor/     编辑器工具（工程配置 / 关卡资产生成）
├── Scenes/     场景
├── Settings/   URP 管线资产与 Volume Profile
└── Scripts/    代码
```

关卡有两种存在形式：Inspector 里可编辑的 ScriptableObject（`Assets/Data`），
以及运行时用的纯数据关卡。游戏内编辑只会产生后者，二者走同一套渲染与模拟流程。

## 构建

`File > Build Settings` 选择 **Windows / x86_64**，加入 `Scenes/Test_2_BitFlow.unity` 后 Build 即可。
