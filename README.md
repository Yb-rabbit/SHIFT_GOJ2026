# SHIFT_GO2026

基于 **Unity 2023.2.20f1 + URP 16.0.6** 的网格解谜原型：摆好元件，按 **PLAY** 观察位流，改完再跑。

## 环境

- Unity Editor：`2023.2.20f1`
- 渲染管线：URP `16.0.6`

## 快速开始

1. 用 Unity Hub 以 `2023.2.20f1` 打开本工程根目录。
2. 打开 `Assets/Scenes/Test_3_BitFlowPlayer.unity`。
3. 按 Play，用底部 **PLAY / PAUSE / STEP / REPLAY** 观察位流推进。
4. 可通过Releases获取作者关卡包（外置）

## 玩法

- 位（0 / 1）由发射器按序列吐出，每个 tick 沿当前方向前进一格。
- 元件会改变位的走向、取值或时机：**分流器**按值分两臂，**非门**取反，**过滤器**只放行指定值，**延迟器**只改到达时间。
- 位撞墙、出界、或从元件出口面逆行撞入 → 销毁。
- 所有接收器都**恰好收满且内容正确**才算通关；悬停元件可看参数。
- 手牌关：先点手牌，再点格子放置；右键拾回自己放的件，`R` 旋转，`Ctrl+Z` 撤销，`ESC` 放下手里的牌。手牌用完为止；`PLAY` 试跑，`REPLAY` 复位。

## 元件说明

手牌只发 6 类（10 种类型资产）；发射器/接收器是出题件，不进手牌。

- 墙 WALL：占位障碍，位撞上即销毁。
- L 分流器 L1：值 1 走一臂、值 0 走另一臂，两臂互成 90°。
- 非门 N1：从任意非出口面进入即取反，从箭头面离开。
- 过滤器 F0 / F1：只放行 0 或 1，另一值销毁；放行值从箭头面离开。
- 延迟器 D1 / D2 / D3 / D4：任意面进入，多停 1~4 tick，再从进入方向的对面原样穿出；不改值、不改路由、不可旋转。
- 暂存器：工具卡BUFFER，点一个锁定预设件把它收回手牌；只对锁定格且非发射器/接收器有效，用一张少一张。
- 发射器 E：按序列循环吐位（末字符先出），总数由关卡定。
- 接收器 R：按目标序列逐位比对并计数，收满且全对才通关；默认四面可收，严格模式只认进料面。

## 关卡编辑

### 游戏内工坊

按 `L` 打开 **MY LEVELS**，点 **+ NEW LEVEL** 进入工坊。调色板选元件，点格子放置；左键已有件可选中改参数，右键拾回。`DONE` 保存，`TEST` 试跑，`CLEAR` 清空，`HOME` 返回选关。

### 外部编辑器

- `Tools/LevelStudio`：浏览器版关卡编辑器，和游戏共用同一份 Core 规则。详见 **[docs/LEVEL_STUDIO.md](docs/LEVEL_STUDIO.md)**。
- `Tools/ShiftGoLevelLab`：单文件离线验关工具，打开 JSON 即可检查并试跑。

游戏内导入走 **MY LEVELS → IMPORT**，支持 **FROM FILE / SHARE FOLDER / CLIPBOARD**。关卡 JSON 的字段与导出/导入流程见 **[docs/LEVEL_JSON.md](docs/LEVEL_JSON.md)**。
