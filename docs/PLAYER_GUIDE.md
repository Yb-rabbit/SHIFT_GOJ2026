# 玩家操作说明（选关 · 手牌 · 工坊 · 关卡文件）

> 面向**在游戏里玩 / 自己做关**的人。全部操作都在 Play 画面内完成，不需要打开任何编辑器窗口。
> 只想改关卡资产或跑批量工具的作者请看 `BUILD_MODE.md`（开发用的 BUILD MODE）与 `LEVEL_JSON.md`。

## 三个工具各干什么（别搞混）

| 你在哪 | 能做什么 | 文档 |
|---|---|---|
| **游戏里 · 手牌盘** | 有限元件解谜：从手牌里点一张放到盘上，把机器接通 | 本页 |
| **游戏里 · 工坊**（`+ NEW LEVEL`） | 从空板开始摆一台机器，自测能跑通后存成一关 | 本页 |
| **游戏里 · 选关面板**（`L`） | 挑关、新建、导入 / 导出 / 删除 / 看 JSON 原文 | 本页 |
| Unity 场景里的 `B` 编辑模式 | 开发工具：无限元件、中文调色板、F5/F9 存读草稿 | `BUILD_MODE.md` |
| 浏览器工具 `Tools/LevelStudio` | 不打开 Unity 做关，用同一份引擎规则自测 | `LEVEL_STUDIO.md` |

**手牌关与 BUILD MODE 不共存**：发了手牌的关卡里，动手能力由手牌盘提供；`B` 编辑模式只留给「没有手牌」的纯沙盒关。
（以前的 bug 就是工坊存的关被挂上了 BUILD MODE，导致手牌盘整排让位、点不动也放不下。）

## 一分钟上手

1. 进关后**点手牌选一张** → 鼠标移到网格上会看到半透明预览 → **左键**放下。
2. 想挪走已放好的元件：**左键点它**（或**空格**抓起）→ 移到目标格 → **再点一次 / 再按空格**放下。
3. 摆好就点 **PLAY**（底部条最左那颗）。跑不通就 **REPLAY** 重来。
4. 想自己做一关：按 **`L`** 开选关 → `+ NEW LEVEL` → 选尺寸 → 工坊开工。

## 暂停面板与音频

游戏中按 **`ESC`** 打开暂停面板（手牌 / 工坊正在占用 `ESC` 时先处理它们，不会同时弹暂停）。
再按一次 `ESC`、点 `RESUME` 或点面板外的暗幕都能继续游戏。

| 控件 | 作用 |
|---|---|
| `RESUME` | 回到游戏 |
| `RESTART` | 重开当前关（回到 `TICK 00`） |
| `LEVEL SELECT` | 打开选关面板 |
| `QUIT` | 退出游戏（编辑器里 = 停止 Play） |
| `AUDIO ON` / `AUDIO OFF` | 总开关。关掉后所有音效静音，但音量数值会记住 |
| `-` / `80%` / `+` | 音量，10% 一档；关掉音频时两颗按钮变灰不可点 |

- 设置**点一下立刻生效并写盘**，没有 `APPLY`；下次启动还是上次的值。
- `RESET PROGRESS` 只清通关勾，**不会**重置音频设置。
- 音量是全局总音量（包含以后加的背景音乐），不走系统音量。

## 手牌盘

| 操作 | 效果 |
|---|---|
| 左键点卡 | 把这张卡拿到手上（卡会抬起来，网格上出现幽灵预览） |
| 左键点格子 | 放下手里的卡；手里没卡时 = 捡起那一格的元件 |
| 右键点卡 | 放下手里的卡（不放置） |
| 右键点格子 | 把那一格的元件收回手牌 |
| **空格** | 抓 / 放（和左键同一件事，一只手就能玩） |
| `R` | 旋转：手上有卡时转**待放朝向**；没卡时转鼠标下那一个 |
| `Ctrl+Z` / `⌘Z` | 撤销上一步（手上提着东西时 = 放下） |
| `ESC` | 放下手里的东西 / 取消选中的卡 |

- 卡上的数字是**还剩几张**，整排上方的 `HAND 2/3` 是「剩 2 张 / 共 3 张」。
- 工坊里没有手牌上限，卡面不显示张数（留空）。
- 演算期间（点过 PLAY）整排手牌会滑出画面：暂停 / 单步 / 重播后自动滑回来。
- 放不下时预览会变红，并给一句原因（越界、那格被占了、牌用完了、那一格是关卡锁定的预设件…）。

## 工坊（自己做一关）

入口：**选关面板（`L`）→ `+ NEW LEVEL` → 选一个尺寸**（9×8 / 11×8 / 7×6 / 13×9）。

工坊里底部四颗按钮换成了作者动作：

| 按钮 | 作用 |
|---|---|
| `DONE` | 自检通过 → 存成一关（`MY LEVEL 01`…），然后回到选关面板 |
| `TEST` | 用真引擎跑一遍；再点一次（变成 `STOP`）= 回到编辑 |
| `CLEAR` | 清空整块板（板上不是空的时要**再点一次**确认） |
| `HOME` | 离开工坊回选关面板（有未保存内容时要**再点一次**确认） |

工坊里的编辑规则：

- 卡排内容是**全部元件类型**，数量无限（卡面不显示张数）；点卡 → 点格子放下，和正式关一样。
- **左键点已有元件 = 选中它**，右侧参数小窗显示/编辑它（序列、次数、朝向、进料面、放行值）。
  想**搬走**它请用**空格**抓起（在工坊里左键是「选中」，不是「捡起」）。
- 右侧参数小窗的 `HAND` 页决定这一关**发不发手牌**：
  - 发了 → 玩家进关后靠手牌盘动手，是「有限元件解谜」；
  - 不发 → 纯展示机器，玩家只能看（除非这关被显式标成可自由涂刷的沙盒）。
- 每次改动都会重建整关并回到 `TICK 00` 暂停，不会出现「改到一半位流在跑」。
- `DONE` 会在存盘前自检，常见拒绝理由（面板上是一句 ASCII，Console 里有中文全文）：

| 面板提示 | 意思 |
|---|---|
| `ADD A RECEIVER` / `ADD AN EMITTER` | 少了接收器 / 发射器 |
| `PRESET ALREADY SOLVES IT` | 你摆的预设布局自己就跑通了，手牌是摆设 |
| `NO EMITTER / RECEIVER CARDS` | 手牌里发的是发射器/接收器，这两类不能当手牌 |
| `TOO MANY CARDS FOR THE BOARD` | 牌比空格还多，玩家永远放不下 |
| `STUCK - CHECK THE ROUTE` | 跑到 tick 上限还没结算：路是断的 |
| `NOT SOLVED - CHECK THE ROUTE` | 通不了，回去对序列 / 朝向 |
| `SAVE SLOTS FULL` | 已经存满 30 关，先去选关面板删几关 |

编辑已有 JSON：选关面板某一行的 `EDIT` 会把它读回工坊接着编；保存后会清掉该文件的旧通关勾（题目改了，旧成绩不再算数）。

## 选关面板

打开方式：**`L`**（任何时候），或通关结算面板里的 `LEVELS`。`ESC` / 再按一次 `L` 关闭。

从上往下三块：

- **内置关卡**：关卡表里的正式关，通关的右边有 `OK`，当前这关标 `NOW`。点一下进去。
- **`MY LEVELS`**：工坊存的关 + 你导入的 JSON 关，副标题是文件名和尺寸。
  - 通关勾按**文件路径**记：把一关复制成另一个文件、即使显示名相同，副本也不会继承原关的 `OK`。
  - `+ NEW LEVEL`：进工坊新建一关（已存满 30 关时会直接退回这里让你先清理）。
  - 每一行右边的 **`...`**：展开这一关的动作 —— `EDIT` / `SHARE · SAVE COPY` / `DELETE · JSON FILE`。
    删除第一次点变成 `PRESS AGAIN`，**3 秒内**再点一次才真删（文件删了没有回收站）。
- **`FILES`**：文件进出（见下一节）。`RESET PROGRESS` 会清掉**所有关卡**的 `OK`（内置关和 MY LEVELS），
  第一次点变成 `PRESS AGAIN`，3 秒内再点一次才生效；已见元件的教学记录不受影响。

列表下方随时会有一行回话：`IMPORTED xxx` / `DELETED xxx` / `SHARED xxx` / `PROGRESS CLEARED` / `SHARE FOLDER IS EMPTY` …

## 关卡文件（导入 / 分享 / 删除）

### 分享目录在哪

玩家之间传关卡只看一个目录：

```
Windows 独立版: <游戏 exe 所在目录>\LevelJson\share\
Unity 编辑器:   <工程根目录>\LevelJson\share\
```

如果游戏装在 `Program Files` 这类不可写的位置，会自动改用 `文档\SHIFT GO\Levels\`。
在面板上点 `SHARE FOLDER` 直接打开，或 `COPY SHARE FOLDER PATH` 把路径复制出来粘进资源管理器地址栏。

目录里只有两样东西：

| 名字 | 是什么 |
|---|---|
| `*.json` | 分享 / 待导入的关卡文件。一个文件 = 一关，文件名不重要（关名写在文件里的 `displayName`） |
| `README.txt` | 这份目录的说明（第一次打开分享目录时自动生成）。只写相对描述、**不含本机路径**，可以随关卡一起转发；旧版说明会在下次启动时自动改写 |

这里的文件**不会自动出现在 MY LEVELS**：先通过 `IMPORT` 导入，才会进游戏自己的关卡库。
游戏内部另有一份正式关卡目录（在系统的 `persistentDataPath` 下），那是运行时存储，玩家不需要手动去翻。

以 `_` 开头的文件（`_template.json` 之类）是模板 / 草稿，**不会**出现在列表里。

### 把外部关卡弄进来（任选一条）

| 做法 | 说明 | 适合 |
|---|---|---|
| `IMPORT · FROM FILE` | 弹系统文件对话框，挑**任意位置**的一个 json | **最常用**：从下载目录 / U 盘 / 聊天记录里直接选 |
| `IMPORT · FROM SHARE FOLDER · BATCH IMPORT` | 把分享目录里能读通的 json 一次全导进来 | 一次给十关 |
| `IMPORT · FROM CLIPBOARD` | 复制一段 JSON 文本 → 点这个 | 别人在聊天软件里直接发了文本 |
| 手动复制文件进分享目录 → `IMPORT · FROM SHARE FOLDER` | 先放进分享目录，再批量导入 | 你已经打开了 `SHARE FOLDER` |
| Unity 菜单 `同步到运行时目录` | 把工程里 `LevelJson\` 单向复制过来 | 作者自测（见 `LEVEL_JSON.md`） |

> 游戏自带的**作者关卡**不用做任何事：第一次启动就已经躺在 `MY LEVELS` 里，和玩家自己造的关一样能进关、编辑、导出、删除。
> 删掉之后不会再冒出来；作者更新了关卡时，**没改过**的那份会跟着更新，**改过**的保留你的版本。
> （浏览器里它们和你的关卡躺在同一份站点存储里，清站点数据一样会没。）

导入的顺序永远是**先验货再落盘**：读不通的 json 一个字节都不写，面板上只留一句
`NOT A LEVEL · SEE CONSOLE`，具体原因同时写在 Console 里。同一份文件重复导入 = 覆盖它自己，不会堆出 `_02`。

> 系统文件对话框只有 **Windows**（编辑器与独立版）有。macOS / Linux 独立版请走分享目录或剪贴板那条路。

### 分享 / 编辑 / 删除

| 按钮 | 作用 |
|---|---|
| `SHARE FOLDER` / `COPY SHARE FOLDER PATH` | 打开 / 复制玩家可见的分享目录 |
| 行内 `...` → `SHARE · SAVE COPY` | 把这一关复制进分享目录（文件名冲突时自动加 `_01`、`_02`，不覆盖已有副本） |
| 行内 `...` → `EDIT · OPEN IN WORKSHOP` | 把这一关读回工坊继续改（`DONE` 写回原文件） |
| 行内 `...` → `DELETE · JSON FILE` | 删这一关的文件（第一次点变成 `PRESS AGAIN`，3 秒内再点一次才真删） |
| `REFRESH` | 重扫正式关卡目录。重开面板也会重扫 |

**删掉正在玩的那一关**：可以删。屏幕上这台机器还在（内存里那份没动），但 `REPLAY` 会退回
「重放内存里这一份」，因为磁盘上已经没有可以重新读的文件了。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 按 `L` 没反应 | 开场演出 / 换关黑幕期间会被挡，等一下再按；Console 有 `没找到 LevelFlow` 说明场景缺组件 |
| 手牌点不动、放不下 | 这关不该有 BUILD MODE。旧版工坊存档可能带着 `allowBuild: true`，现在进关会对手牌关强制摘掉，重进这关即可 |
| 点了 `IMPORT · FROM FILE` 没弹窗 | 只有 Windows 支持系统对话框；其它平台把文件丢进 `SHARE FOLDER`，用 `IMPORT · FROM SHARE FOLDER`。Windows 上如果 Console 里出现 `打不开文件对话框（CommDlgExtendedError=...）`，那说明系统拒绝了这次调用（例如被安全软件拦截），同样先走分享目录 |
| 导入后列表里没有 | 看那行状态：`NOT A LEVEL`（JSON 读不通，原因在 Console）或 `SHARE FOLDER IS EMPTY`（分享目录里没有可导入的文件） |
| `IMPORT · FROM SHARE FOLDER` 导不进 | 文件要放在**分享目录**里（点 `SHARE FOLDER` 打开的就是它）；分享目录里的文件要先导入，不会自动出现在列表 |
| 行内 `...` 的删除点了没反应 | 第一次点只是「举手」（变成 `PRESS AGAIN`），3 秒内再点一次才真删 |
| 复制 / 另存的关卡也显示 `OK` | 旧版 JSON 通关记录按显示名记，和内置关同名就会串档；现在按文件路径记，副本不会继承原关的勾 |
| 打包后想清掉默认关卡的 `OK` | 选关面板 → `FILES` → `RESET PROGRESS`，第一次点变成 `PRESS AGAIN`，3 秒内再点一次才清空 |
| `DONE` 不让我存 | 面板上那行 ASCII 就是原因，对照上面的工坊表；中文全文在 Console |
| 改完关卡「不生效」 | 本页所有编辑都只作用于内存草稿；`DONE` 才会写文件，写的是游戏的运行时关卡目录，`Assets/Data` 的资产不会变 |
| 位流不动 | 每次改动都会自动暂停并回到 `TICK 00`，点 `PLAY` 或 `STEP` 继续 |
| 没有声音 | 按 `ESC` 看暂停面板：`AUDIO OFF` 就点回 `AUDIO ON`，再看音量是不是 0%；音效文件在 `Assets/Audio/SFX`，清单在 `Resources/BitFlow/SfxLibrary` |
| 重启后音量变了 | 设置存在存档里（编辑器是 `save_editor.json`，打包版是 `save.json`）；删存档 = 恢复默认开 / 80% |

## 改完这些功能后怎么验证

EditMode 测试覆盖运行时那条链路（选关 → 读盘 → 建关）：

```
Window > General > Test Runner > EditMode > Run All
```

重点类：

- `LevelJsonLibraryTests` —— 目录扫描、验证、**导入（文件 / 收件箱）**、删除、投放目录
- `SaveStoreTests` —— 通关记录的身份规则（JSON 关按文件路径，不按显示名）
- `LevelJsonTests` —— JSON ↔ 关卡定义往返
- `LevelSupplyTests` / `PlayerDraftTests` —— 手牌（发得出、放得下、`kind` 不丢）
- `LevelDocumentBuilderTests` —— 工坊存档用的文档格式

实现位置：

- `Runtime/View/LevelSelectPanel.cs` —— 面板（列表、行级删除、`FILES` 动作、`L` 热键）
- `Runtime/Data/LevelJsonLibrary.cs` —— 目录、扫描、导入、删除
- `Runtime/Data/FilePicker.cs` —— 系统文件对话框（Windows P/Invoke / 编辑器）
- `Runtime/View/BitFlowWorkshop.cs` / `BitFlowCardTray.cs` —— 工坊与手牌盘
