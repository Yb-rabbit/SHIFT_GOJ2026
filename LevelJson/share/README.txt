SHIFT GO README v2 · 关卡分享 / 导入目录
========================================

这个目录是给玩家之间传关卡用的：
  1. 别人发来的 .json 放进这里；
  2. 游戏里：选关面板 → IMPORT → FROM SHARE FOLDER · BATCH IMPORT；
  3. 你自己的关卡：MY LEVELS 那一行 ... → SHARE · SAVE COPY 也会存到这里。

注意：这里的文件不会自动出现在 MY LEVELS，导入成功后才会进游戏自己的关卡库。
导出 / 分享只是把文件复制到这里，不会覆盖已有的同名文件。

本文件所在的目录就是分享目录（游戏里 SHARE FOLDER 打开的就是它）；
不同电脑上的路径不一样，所以说明里不写死路径。
